# Preply

> Preply is a global online language-learning marketplace connecting learners with private tutors across many languages. Preply publishes a small public, unauthenticated ChatGPT-plugin API for searching tutors, plus an enterprise Preply Business offering with SSO, automated provisioning and LMS integrations.

## API

- [Preply plugin OpenAPI](https://preply.com/openapi.yaml): Public read-only tutor-search API (2 GET operations, no auth). Base: https://preply.com/api/chatgpt_openapi/
- [ai-plugin.json](https://preply.com/.well-known/ai-plugin.json): OpenAI plugin manifest
